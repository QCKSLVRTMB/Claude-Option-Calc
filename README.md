# 📊 MOEX Options Calculator

Профессиональный калькулятор опционов MOEX с поддержкой Black-Scholes модели, управлением позициями и анализом волатильности.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://options-calc.streamlit.app)
[![Python 3.11+](https://img.shields.io/badge/Python-3.11%2B-blue)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 🎯 Возможности

- ✅ **Black-Scholes калькулятор** — расчёт теоретической цены и греков
- 📈 **Анализ волатильности** — IV Rank, Heatmap, Skew детектор
- 💼 **Управление позициями** — сохранение и отслеживание портфеля
- 📓 **Журнал сделок** — ведение истории с возможностью анализа
- 💾 **Кеш между сессиями** — JSON export/import
- 📱 **Адаптивный дизайн** — работает на ПК и мобильных
- ☁️ **Cloud-ready** — развёрнут на Streamlit Community Cloud
